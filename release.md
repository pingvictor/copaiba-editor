# COPAIBA TOUCH @ Alpha is here!

COPAIBA Web is now COPAIBA TOUCH. We have just released a major update focused on mobile productivity and visual precision.

### What's New:
- **Mobile First**: Fully responsive UI with a dedicated footer toolbar (Undo, Redo, Play, Navigation).
- **High Contrast Design**: New Slate and Sky theme with enhanced waveform visibility in both Light and Dark modes.
- **Phonetic Presets**: One-tap macros for CV, VC, VCV, and VV transitions.
- **Improved Interaction**: 30-step Undo/Redo history and native touch support for markers.
